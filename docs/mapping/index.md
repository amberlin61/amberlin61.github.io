# 三种建图方法总览

## 从估计问题看三种路线

### 1. 编码器逐点补偿

已知机械运动，求每个点在统一坐标系中的位置：

```text
逐点时间 + 编码器轨迹 + 固定转轴/外参 → 点坐标变换 → 体素地图
```

它解决的是**已知运动下的点云去畸变和拼接**，不从点云反求轨迹。

### 2. FAST-LIO2风格卡尔曼建图

已知IMU测量和激光点云，联合估计运动状态：

```text
IMU传播 → 逐点去畸变 → 点到地图平面残差 → 迭代状态更新 → 增量地图
```

它解决的是**一般六自由度运动下的LiDAR–IMU里程计与局部建图**。

### 3. 编码器约束站点全局优化

已知离散站点的编码器角度，并能建立站间点云重合约束：

```text
站内融合 → 编码器初值 → 站间ICP → 转轴拟合 → SE(3)位姿图 → 全局地图
```

它解决的是**一组停扫站点在机械先验和点云约束下的批量一致性优化**。

## 能力比较

| 维度 | 编码器逐点补偿 | FAST-LIO2风格卡尔曼 | 站点全局优化 |
| --- | --- | --- | --- |
| 必需传感器 | LiDAR、编码器 | LiDAR、IMU | LiDAR、编码器 |
| 运动模式 | 固定轴连续旋转 | 一般六自由度运动 | 离散停站 |
| 点云配准 | 无 | 增量scan-to-map | 站内、站间ICP |
| 时间同步敏感性 | 很高 | 很高 | 中等；站内仍需时间一致 |
| 外参敏感性 | 很高 | 很高 | 初值敏感，可由重叠约束修正部分残差 |
| 回环检测 | 无 | 无 | 固定一圈测量环，不是通用场景回环 |
| 全局位姿图 | 无 | 无 | 有，限定于本次站点图 |
| 实时性 | 高 | 中到高 | 封帧后计算 |
| 主要退化条件 | 时间、转轴或外参错误 | IMU初始化失败、局部平面退化 | 重叠不足、ICP错误边、站点缺失 |

## 选择逻辑

- 运动严格受机械转轴约束、编码器可靠：优先考虑编码器逐点补偿。
- 传感器发生一般空间运动且有可靠IMU：考虑FAST-LIO2风格卡尔曼建图。
- 允许停站采集，希望利用点云重合修正机械残差：考虑站点全局优化。
