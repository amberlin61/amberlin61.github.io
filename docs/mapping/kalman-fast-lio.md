公开基线采用GPL-2.0许可。发布派生代码时需要继续核对许可证义务；这里的笔记只描述算法原理和版本关系。

## 2. 问题定义

给定高频IMU测量和离散LiDAR扫描，连续估计传感器状态，并将每个激光点变换到统一地图坐标系。

典型状态包含：

```text
x = {R, p, v, bg, ba, g, R_LI, t_LI}
```

其中：

- `R, p, v`：IMU在世界坐标系中的姿态、位置和速度；
- `bg, ba`：陀螺仪与加速度计零偏；
- `g`：重力向量；
- `R_LI, t_LI`：LiDAR到IMU的外参，可固定或估计。

姿态属于旋转流形，不能像普通欧氏向量那样直接相加，因此实现使用IKFoM风格的流形误差状态滤波。

## 3. 算法流程

```text
静止IMU初始化
      │
      ▼
IMU状态传播 ──► 扫描内逐点去畸变
      │                 │
      │                 ▼
      └────────── 当前扫描点
                        │
局部ikd-Tree地图 ─► 邻域搜索与平面拟合
                        │
                        ▼
               点到平面观测残差
                        │
                        ▼
               迭代误差状态更新
                        │
                        ▼
                  地图增量更新
```

## 4. 静止初始化

启动阶段收集一段静止IMU：

- 平均角速度用于估计陀螺零偏；
- 平均加速度方向用于估计重力方向；
- 方差用于判断设备是否真的静止。

如果设备在初始化期间运动，重力和零偏会混在一起，后续传播会快速产生姿态和位置误差。因此静止检测属于算法可观测性的必要条件，不只是工程检查。

## 5. IMU传播

忽略离散化细节，连续模型可写为：

```text
Ṙ = R · Exp(ωm - bg - ng)
ṗ = v
v̇ = R(am - ba - na) + g
ḃg = nbg
ḃa = nba
```

滤波器同时传播状态和协方差。传播结果为激光扫描内每个时刻提供姿态初值。

## 6. 逐点去畸变

一帧点云并非同一瞬间生成。根据点的相对时间，在IMU传播轨迹上查询该点姿态，再把所有点补偿到统一参考时刻：

```text
p_ref = T_ref^-1 · T(t_point) · T_I←L · p_L
```

缺少逐点相对时间时，快速运动会把一个平面拉成弯曲或分层结构。

## 7. 点到局部平面残差

对去畸变后的点，在ikd-Tree地图中寻找邻域，拟合局部平面：

```text
nᵀx + d = 0
```

点的观测残差为：

```text
r = nᵀ(Rp_L + t) + d
```

对状态线性化后得到观测雅可比。迭代误差状态卡尔曼滤波反复更新状态，直到增量足够小或达到迭代上限。

## 8. 增量地图

状态收敛后，将当前点云插入ikd-Tree。ikd-Tree支持：

- 动态插入和删除；
- 邻域搜索；
- 局部地图裁剪；
- 树内降采样；
- 动态重平衡。

这使局部scan-to-map可以持续运行，而无需每帧重建整棵静态KD树。

## 9. 相对FAST-LIO2基线的当前适配

### 9.1 提取无ROS计算核

保留IKFoM、ikd-Tree和SO(3)数学源码，移除ROS topic、TF、launch、PCD写盘和原进程生命周期。点云和IMU以强类型内存数据直接进入计算核。

这主要是架构适配，不是新的状态估计理论。

### 9.2 每路传感器独立滤波器

每个LiDAR–IMU组合拥有独立状态、外参、初始化过程和局部地图，避免不同设备的时间和状态混入同一滤波器。

### 9.3 初始化与质量门禁显式化

将静止加速度方差、角速度、重力模长、有效平面点数、邻域距离、平面阈值、迭代收敛和IMU间隔分别配置和检查。初始化失败不会通过关闭后续质量门禁绕过。

### 9.4 编码器退出状态估计

在该后端中，编码器只负责机械控制和扫描边界，不参与六自由度位姿估计。位姿由IMU传播和点到平面观测更新得到。

### 9.5 统一体素输出

滤波器内部维护ikd-Tree局部地图，最终结果转换为统一的体素sum/count记录，使其能够和其他建图后端使用相同的地图输出格式。

## 10. 当前实现没有增加的能力

- 没有通用场景回环检测；
- 没有全局位姿图优化；
- 没有视觉约束；
- 没有改变FAST-LIO2的基本“IMU传播 + 点到地图平面更新”框架；
- 没有因为接入编码器而变成编码器融合里程计。

因此应称为“FAST-LIO2/IKFoM风格的LiDAR–IMU里程计与增量建图适配”，不应描述成新的LIO理论。

## 11. 主要退化条件

- IMU静止初始化不可靠；
- LiDAR与IMU时间不同步；
- LiDAR–IMU外参错误；
- 场景局部几何退化，例如只有单一平面或长直走廊；
- 点云过稀，无法稳定拟合局部平面；
- 强振动或IMU饱和使传播模型失真。
