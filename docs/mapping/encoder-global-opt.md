# 编码器约束站点子图全局优化

## 2. 问题定义

雷达安装在带编码器的旋转机构上。电机停在一组离散角度，每个角度采集一段静止点云。编码器提供站点初始姿态，点云重合提供相对位姿观测。

目标是联合估计：

- 每个站点相对于首站的六自由度位姿；
- 所有站点共享的旋转轴方向和轴上参考点；
- 编码器角度比例或系统性角度修正；
- 一圈范围内几何一致的全局点云。

## 3. 为什么需要全局优化

只使用编码器纯旋转模型时，轴方向、轴心、零角和角度比例的微小误差会让同一物体在不同站点错位。

只做相邻站点ICP时，局部误差会沿站点链传播，最后一站可能无法与第一站闭合。

因此使用两类约束：

1. **编码器运动学先验**：给出稳定但可能有偏差的初值；
2. **LiDAR注册测量**：根据站点点云重合修正相对位姿。

## 4. 真实停站采集模型

当前方法按一圈24个站点组织数据，站点间隔为15°。每站流程是：

```text
到达目标角度 → 确认稳定 → 电机失能 → 采集静止窗口 → 进入下一站
```

默认每站采集800 ms，并按100 ms分成8个微帧。运动和停稳确认期间的点不进入该站点。

24站和具体时间是当前基线参数，不是算法理论的固定常数。减少站点数会改变重叠、可观测性和闭环约束，必须重新验证。

## 5. 站内微帧融合

同一站点内仍可能有轻微振动和采样差异。算法以首个微帧为参考，对后续微帧执行粗到细点到面ICP：

```text
体素尺度：0.10 m → 0.05 m → 0.03 m
```

只有平移、旋转、有效点数和残差满足门禁的微帧才加入站点子图。这样单个异常微帧不会直接破坏整个站点。

## 6. 编码器运动学初值

设首站坐标系为固定参考，粗略转轴为单位向量 `a0`，轴上参考点为 `c0`，第 `i` 站编码器相对角为 `θi`。

编码器给出的初始站点位姿为：

```text
T_i^0 = AxisTransform(a0, c0, θi)
```

`a0`和`c0`只负责把ICP放进正确的收敛盆地，不被当成最终标定结果。

## 7. 站间粗到细点到面ICP

对具有足够视场重叠的站点对 `(i,j)`，以编码器相对运动为初值，最小化：

```text
E_ij(T_ij) = Σk ρ(n_kᵀ(T_ij p_k - q_k))
```

其中：

- `p_k`：源站点；
- `q_k, n_k`：目标站点中的对应点和平面法向；
- `ρ`：Huber鲁棒核。

ICP同样按粗到细体素尺度运行。粗尺度扩大收敛范围，细尺度提高局部精度。

## 8. 双向一致性与测量边

分别计算：

```text
T_i→j 与 T_j→i
```

理想情况下：

```text
T_i→j · T_j→i ≈ I
```

只有正反向注册都通过以下检查，才形成正式测量边：

- 有效对应点和inlier数量；
- 局部几何可观测性；
- 相对编码器初值的偏离；
- 正反向平移、旋转一致性。

单方向ICP收敛不代表匹配正确，双向一致性用于拦截部分局部极小值。

## 9. 共享转轴与角度模型拟合

有效LiDAR测量边共同约束所有站点。算法拟合一条共享旋转轴，并允许编码器角度比例和每站角度存在小修正。

抽象模型为：

```text
T_i^axis = AxisTransform(a, c, s·θi + δθi)
```

其中：

- `a`：优化后的共享轴方向；
- `c`：轴线上距离原点最近的参考点；
- `s`：编码器角度比例；
- `δθi`：第 `i` 站的小角度修正。

共享模型比给每个站点完全自由的六自由度更符合机械结构，也能降低小数据下的过拟合。

## 10. SE(3)位姿图优化

固定站点0作为gauge，避免整体地图的任意刚体自由度。优化目标可以概括为：

```text
min {T_i,a,c,s,δθ_i}
    Σ(i,j) ρ( || Log(Z_ij^-1 · T_i^-1 · T_j) ||²_Ωij )
  + λ Σi ρ( || Log((T_i^axis)^-1 · T_i) ||²_Λ )
```

第一项是LiDAR注册测量边，第二项是共享转轴运动学软先验。`soft_l1`鲁棒损失降低少量异常边对整体结果的破坏。

注册边自身必须连通并形成完整360°测量环。编码器先验不会被伪装成LiDAR边来补足一个断开的图。

## 11. 全局地图生成

优化通过质量门禁后，用最终站点位姿重投影所有站点体素：

```text
p_global = T_i* · p_station_i
```

随后按统一最终体素大小合并，得到一圈全局地图。

如果测量环、转轴拟合、图残差或节点修正量不合格，算法失败。编码器初始地图和中间checkpoint不作为成功结果回退输出。

## 12. 相对Python基线的当前改进

### 12.1 独立C++17重写

当前版本没有复制无许可证Python源码，而是重新实现体素化、点到面ICP、共享轴拟合和SE(3)位姿图，并使用固定数据回放核对结果。

### 12.2 从虚拟站点改为真实停站

早期C++版本曾把连续运动点按角度归入虚拟站点。当前版本要求电机实际到站、停稳、失能后采集，减少站内运动模型误差。

### 12.3 增加站内微帧融合

先处理同一站点的短时微帧，再进行站间注册，使站间ICP输入更稳定，并能隔离单个异常微帧。

### 12.4 加强测量边验证

引入正反向注册、几何可观测性、初值偏离和完整测量环检查，避免局部ICP成功但全局拓扑错误。

### 12.5 共享转轴联合拟合

不是简单把24个站点当作互不相关的自由位姿，而是先从有效边联合拟合机械轴、角度比例和站点角度修正，再作为位姿图软先验。

### 12.6 严格终态

全局优化失败时不把编码器基线图标记为成功结果，防止数值失败被回退路径隐藏。

### 12.7 缓存与工作集控制

粗到细体素、法向和邻域结构预计算并复用；最终化前估计ICP、KD树、位姿图和输出体素的峰值工作集。这是数值实现和资源稳定性改进，不改变优化目标。

## 13. 与通用回环SLAM的区别

这里的“闭环”是预先知道站点按一圈排列，并要求相邻站点测量边形成完整360°环。它不是在未知场景和长轨迹中进行地点识别的通用回环检测。

## 14. 主要退化条件

- 站点数量太少或相邻视场重叠不足；
- 场景缺少稳定平面和三维结构；
- 大量动态物体破坏站间对应；
- 编码器初值离真实运动过远，ICP离开收敛盆地；
- 某些站点缺失，使LiDAR测量图无法形成完整环；
- 场景关于转轴高度对称，部分轴参数不可观测。
