# 编码器逐点补偿建图

## 1. 来源与固定基线

### 来源结论

当前可核对的仓库历史中，**没有发现该方法直接派生自某个公开SLAM项目**。它是固定旋转机构的内部建图实现，最早以 `MultiEncoderSlam` 形式进入当前算法分支。

可追溯基线：

| 项目 | 记录 |
| --- | --- |
| 内部算法版本 | `R1_Multiple-encoders_SLAM@1.2.0` |
| 首次接入提交 | `efe065f9a8206ce133a34ae2bca5247336d0824f` |
| 后续倾斜转轴支持 | `870a69e6ac1264c297777ff38f010e226a1cd8c4` |
| 外部开源基线 | 未发现可验证来源 |

历史文档提到该实现迁移了两个旧分支中已验证的固定旋转建图语义，但当前克隆没有保留那两个旧分支的名称和提交，因此不能继续声称更早的精确版本来源。

## 2. 问题定义

设激光雷达刚性安装在旋转机构上。机构绕固定轴转动，编码器给出角度和角速度。目标是把不同时刻测得的激光点转换到同一个静止坐标系中。

输入：

- 每个激光点在雷达坐标系中的坐标 `p_L`；
- 每个点的测量时间 `t_p`；
- 离散编码器样本 `(t_k, θ_k, ω_k)`；
- 转轴方向、轴心、安装偏心和固定外参。

输出：统一坐标系中的体素点云。

## 3. 基本假设

1. 雷达、支架与转轴之间是刚体关系；
2. 运动主要由一个可测的旋转自由度决定；
3. 编码器角度连续且覆盖所有点的测量时间；
4. 点时间和编码器时间可以转换到同一时间轴；
5. 转轴、零角和安装外参已知。

这些假设成立时，不需要从点云配准反推姿态。

## 4. 编码器角度插值

一个点的查询时间为：

```text
t = t_p + Δt
```

`Δt`表示两套时间轴之间剩余的固定偏移。找到包围该时间的两条编码器样本：

```text
(t0, θ0, ω0), (t1, θ1, ω1)
```

令：

```text
s = (t - t0) / (t1 - t0)
```

使用带端点角速度的三次Hermite插值：

```text
h00 =  2s³ - 3s² + 1
h10 =   s³ - 2s² + s
h01 = -2s³ + 3s²
h11 =   s³ -  s²

θ(t) = h00 θ0 + h10 (t1-t0)ω0
     + h01 θ1 + h11 (t1-t0)ω1
```

相较于只对角度做线性插值，这种方式同时利用端点速度，使匀速和缓慢变速段更加连续。编码器间隔过大时应拒绝插值，因为任何低阶模型都无法恢复区间内未观测到的真实振动。

## 5. 逐点坐标变换

设：

- `a`：单位转轴方向；
- `c`：轴心或轴线参考点；
- `θ0`：任务零角；
- `d∈{−1,+1}`：编码器方向；
- `T_A←L`：雷达坐标系到零角轴坐标系的刚体变换；
- `T_M←A`：轴坐标系到地图坐标系的固定变换。

修正角度为：

```text
φ(t) = d · (θ(t) - θ0)
```

点变换可以概括为：

```text
p_M = T_M←A · Rot(a, φ(t)) · T_A←L · p_L
```

如果安装偏心以转轴零位坐标表示，则偏心向量只随编码器角度旋转，不跟随可选IMU残差旋转。

## 6. 体素融合

变换后的点按体素边长 `v` 离散：

```text
key = floor(p_M / v)
```

每个体素累加：

```text
Σx, Σy, Σz, Σintensity, count
```

最终输出均值。体素化限制地图规模并抑制重复采样带来的点数膨胀，但体素大小不等于测距精度。

## 7. 算法流程

```text
逐点坐标与时间
       │
       ├── 时间轴校正
       │
编码器样本 ── Hermite插值 ── 得到逐点角度
       │
       └── 转轴/外参变换 ── 距离门禁 ── 体素均值 ── 地图
```

伪代码：

```cpp
for (const Point& point : frame) {
    Time tq = point.time + residual_time_offset;
    EncoderPair pair = bracket(encoder_samples, tq);
    double angle = cubicHermite(pair, tq);
    Vec3 mapped = fixedTransform * rotateAroundAxis(point.xyz, angle);
    voxelMap.accumulate(mapped, point.intensity);
}
```

## 8. 相对基线的当前改进

### 8.1 任意三维倾斜转轴

早期模型更接近竖直轴旋转。后续版本把转轴推广为任意单位向量，并支持三维轴心偏移，使算法能够表示倾斜安装和一般三维杠杆臂。

### 8.2 多源与确定性体素输出

每路点云绑定独立编码器、时间偏移、转轴和外参；体素以确定性sum/count形式累计，便于分块排出后保持与一次性计算相同的均值结果。

### 8.3 可选IMU区间约束

基线实现允许在两个编码器端点之间积分IMU角速度，再用编码器端点姿态平滑约束区间轨迹。纯编码器模式可以关闭该路径。

### 8.4 倾向于严格失败而非外推

当前实现要求编码器时间覆盖每个点，并限制最大编码器间隔。时间无覆盖、样本乱序或间隔过大时停止建图，不用无约束外推伪造角度。

### 8.5 时间与角度预处理增强

在固定数值内核和固定外参下，进一步验证过三项输入侧增强：

1. 用稳健仿射模型把雷达设备时钟映射到主机时间轴；
2. 用电机角度请求/应答中点估计真实角度采样时刻；
3. 对编码器轨迹做固定参数稳健平滑。

这三项改善的是 `θ(t)` 的输入质量，没有改变逐点旋转与体素融合公式。离线对照中，主要收益来自前两项精确时序；轨迹平滑提供较小的追加收益。

## 9. 误差特性

该方法不递推上一帧的点云位姿，所以没有典型里程计式的递推漂移。但固定误差会在每圈重复出现：

- 时间偏移导致角度错配；
- 转轴方向错误导致距离越远、错层越明显；
- 轴心或偏心错误导致周期性平移残差；
- 编码器量化、轮询延迟和轴摆造成圈间厚度；
- 支架振动破坏单自由度刚体假设。

## 10. 能力边界

- 不执行ICP、NDT或scan-to-map；
- 不从点云估计六自由度轨迹；
- 不进行场景回环检测；
- 不进行全局位姿图优化；
- 无法自动区分外参误差、时间误差和机械形变。

因此它更接近“机械运动模型驱动的逐点去畸变与地图融合”，不是通用移动机器人SLAM。
